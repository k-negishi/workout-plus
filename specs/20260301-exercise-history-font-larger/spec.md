# 仕様書: 種目履歴画面の見出し・日付フォントサイズ拡大

## GitHub Issue
https://github.com/k-negishi/workout-plus/issues/213

## 概要

`ExerciseHistoryFullScreen` の見出し文字と日付文字が小さく視認性が低い。
ヘッダータイトル・セクション見出し・日付のフォントサイズを拡大して読みやすくする。

## 現状

| 対象要素 | 現在の fontSize |
|---------|---------------|
| ヘッダータイトル（種目名） | 17px |
| セクション見出し（className: text-sm） | 14px |
| 日付テキスト | 13px |

## 要件

### 機能要件

- [ ] ヘッダータイトル（種目名「ベンチプレス」等）を 17px → **20px** に変更する
- [ ] セクション見出し3箇所（「直近3ヶ月の最大RM推移」「PR (自己ベスト) 履歴」「全履歴 (N回)」）を `text-sm`（14px）→ **`text-base`**（16px）に変更する
- [ ] 全履歴リストの日付テキスト（「1月30日(金)」等）を 13px → **15px** に変更する

### 非機能要件

- 既存のレイアウト・配置（中央揃え、flex配置等）は変更しない
- fontWeight・color は変更しない
- StatCard・セット行（18px）・1RMサブテキスト（13px）は変更対象外

## ユーザーストーリー

- **US-1**: ユーザーとして、種目履歴画面の見出し・日付を見たとき、現在より文字が大きく一目で把握できることを期待する

## 影響範囲

| ファイル | 変更内容 |
|---------|---------|
| `apps/mobile/src/features/exercise/screens/ExerciseHistoryFullScreen.tsx` | fontSize 3箇所変更、className 3箇所変更 |

## 除外事項

- StatCard内の数値・ラベル（別Issue対応済み）
- セット行の重量×rep数フォント（18px）
- ホーム画面・カレンダー画面のフォント
